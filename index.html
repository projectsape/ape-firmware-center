01 / HARDWARE

SUPPORTED DEVICES

Select the exact hardware family. T147 uses one shared card, then asks whether you are flashing the LoRa or NoLoRa build.

BEFORE YOU SELECT

Identify the board from its printed model or original packaging.

Do not select by appearance alone. The flasher checks the ESP32 family and, when the chip reports it, flash size. It cannot identify the exact board revision or the firmware layout already installed.

02 / CONNECTION & RECOVERY

IF THE BOARD DOES NOT CONNECT OR BOOT

01

Port not listed

Use desktop Chrome or Edge and a USB data cable. Close other serial tools, reconnect the board and try again. Charge-only cables do not expose a serial port.

02

Download mode

Follow the board manufacturer's documented bootloader procedure. BOOT/RESET sequences differ between products, so this site does not prescribe one universal sequence.

03

Interrupted or unbootable

Reconnect the same target and retry. A clean install can recover an incompatible update, but it erases the entire flash, including firmware, settings and stored data.

What the integrity check means

Every downloaded artifact is SHA-256 checked against this site's catalog before writing. This detects a corrupt or mismatched download; it is not a digital signature and does not independently authenticate the publisher.
